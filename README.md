# 🚀 OpportunityOS

OpportunityOS is a career guidance platform designed to help students explore career paths, identify skill gaps, and make informed learning decisions.

The platform provides personalized career roadmaps and skill gap analysis for various technology domains, helping users understand what skills they need to develop to achieve their target roles.

## 🌐 Live Demo

**Live Website:** https://opportunityos-r8ie.onrender.com

---

## ✨ Features

### 🛣️ Career Roadmap Generator

Generate structured learning roadmaps for different career paths:

* AI Engineer
* Web Developer
* Cyber Security

Users can explore the technologies, tools, and skills required to progress in their chosen field.

### 📊 Skill Gap Analyzer

Analyze your current skills and compare them with the skills required for a target role.

The platform highlights:

* Existing skills
* Recommended skills
* Areas for improvement

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/divyaamakhija/OpportunityOS.git
```

### Navigate to the Project

```bash
cd OpportunityOS
```

### Run the Application

```bash
./gradlew bootRun
```

### Open in Browser

```text
http://localhost:8080
```
